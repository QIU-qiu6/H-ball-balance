# H 题视觉钢球平衡系统

基于 MaixCAM-Pro、STM32F103C8T6 和 Emm 固件闭环步进电机的单轴钢球平衡工程。摄像头识别钢球并通过串口发送位置，STM32 根据位置与速度估计调节电机，使钢球向记录的目标点运动并保持。

本仓库于 2026-09-10 从现有工程整理，范围为视觉与平衡部分，不包含小车底盘循迹控制。它是调试中的工程快照，不代表 H 题全部指标已经通过实测验收。

## 工程入口

| 目录 | 内容与入口 |
| --- | --- |
| `stm32/` | Keil 工程，打开 `gimbal_dual.uvprojx` |
| `maixcam/` | MaixVision 工程，入口 `main.py`，使用 MaixHub 297541 模型 |
| `ARM/` | 当前工程引用的 CMSIS 与 STM32 标准外设库源码子集 |
| `docs/` | 接线、调试状态、来源与验证说明 |

STM32 当前参与编译的平衡控制文件为 `CONTROL/gimbal/gimbal_reference.c`。同目录的 `gimbal.c` 是保留的历史实验实现，未加入当前构建，不要同时加入工程。

## 快速开始

1. 安装 Keil MDK，准备 ARM Compiler 5。工程使用 STM32F103C8T6；编译器及授权不随仓库分发。
2. 保持 `stm32/` 与 `ARM/` 为相邻目录，打开 `stm32/gimbal_dual.uvprojx` 并重新编译。编译输出位于 `stm32/build/`。不要使用未核对来源的旧 HEX 文件。
3. 在 MaixVision 中打开 `maixcam/` 文件夹，根目录应直接包含 `main.py`、`app.yaml` 和两个模型文件。
4. 连接 MaixCAM-Pro 并运行项目；先用串口助手确认位置数据，再接 STM32 联调。需要支持该模型和 `maix.nn.YOLOv5` 的 MaixPy 固件；原工程未记录精确固件版本。
5. 先阅读 [接线与通信](docs/WIRING.md) 和 [当前状态](docs/STATUS.md)，确认按键映射、机械零点和停止动作后再测试电机。

## 视觉与通信

摄像头采集 640×480 图像，模型输入为 224×224。失去目标后按三个窗口搜索，识别到钢球后窗口跟随目标。输出坐标已还原到原始 640×480 图像。

串口：UART1，A19/TX、A18/RX，115200、8N1。发送示例：

```text
X:336,Y:340,W:29,H:28
NO_TARGET
UART1_ALIVE:20
```

实际消息以 `\r\n` 结尾。程序启动还会发送启动标识和阶段信息。当前 STM32 通过 PA3 接收坐标；PA2 发送功能在代码中关闭。

## 平衡控制

位置环根据视觉位置、速度估计与预测位置产生角度目标，内环根据电机位置反馈产生转速命令。包含滤波、输出限幅、积分限制和目标角度变化限制。

这里使用电机角度反馈；连杆机构使电机轴角度与轨道倾角不相等，不应直接把电机角度当作轨道倾角代入理论模型。实际增益和零点需按机械装配重新验证。

历史标定为远端 X=53、中点 X=336、近电机端 X=606，有效行程约 240 mm。摄像头移动或轨道结构变化后需要重新标定。
